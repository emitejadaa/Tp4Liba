# LIBA — Landing del torneo

Landing de **LIBA**, una liga amateur de básquet 3v3 que se juega los domingos en Palermo, Buenos
Aires.

El sitio se construye a partir del diseño de Figma del torneo y suma interacciones de scroll, hover
y tap, además de un minijuego de tiro al aro.

> El proyecto se desarrolla por pull requests: cada bloque de la landing entra por su propia rama.
